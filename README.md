## About

I build software that businesses actually run on: admin consoles, management systems, SaaS products, APIs, and the cloud infrastructure underneath them.

**How I work**

- **Own the whole problem.** Requirements, data model, UI, API, deployment, and the fixes after launch — one person, no hand-off gaps.
- **Boring where it matters.** Proven frameworks (NestJS, Spring Boot, React, Angular), typed code, and clear database design, so the next developer can read it.
- **Built to grow.** Modular backends, indexed queries, and stateless services that scale on AWS without a rewrite.
- **Secure by default.** Role-based access, validated inputs, secrets kept out of code, and least-privilege cloud permissions.
- **Clear communication.** Written scope, regular demos, and honest estimates — no surprises at the invoice.

**Who I work with:** startup founders, small and mid-sized businesses, agencies needing a reliable development partner, entrepreneurs building SaaS products, and companies that need a dedicated developer for a long-term product.

## How I Deliver

```
 Discovery ──▶ Planning ──▶ UI/UX ──▶ Development ──▶ Testing ──▶ Deployment ──▶ Maintenance
```

| Stage | What you get |
| :-- | :-- |
| **Discovery** | A call to understand your users, goals, budget, and constraints |
| **Planning** | Written scope, architecture, milestones, and a fixed or hourly estimate |
| **UI/UX** | Wireframes and screen flows approved before code is written |
| **Development** | Weekly progress demos and access to a staging environment |
| **Testing** | Functional, API, and edge-case testing before every release |
| **Deployment** | Production setup on your cloud account, with domain, SSL, and CI/CD |
| **Maintenance** | Bug fixes, monitoring, updates, and new features after launch |
